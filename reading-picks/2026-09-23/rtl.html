RTL · EDA · ENGINEERING NOTE

Spec-to-RTL 에이전트가 PPA 루프까지 들어왔다

Cadence의 새 ChipStack RTL Generation Agent는 자연어 spec에서 RTL을 만들고, EDA 분석 결과를 다시 받아 PPA와 기능 정확도를 반복 개선하는 방향을 제시한다.

핵심은 LLM 단독 RTL 생성이 아니라, 실제 EDA 평가를 폐루프에 넣는 것이다.
Futurum Group · Brendan Burke · 2026-09-23 · 약 8~10분

핵심 내용

Cadence가 ChipStack AI Super Agent에 RTL Generation Agent를 추가했다. 자연어 specification에서 RTL을 생성하는 것뿐 아니라 RTL analysis와 refinement를 연결하고, PPA를 설계 목표에 포함한다. 초기 평가에서 Cadence는 foundation-model-only 생성 대비 평균 24% area, 18% power 개선과 기능 정확도 100%를 주장한다. 이 수치는 vendor 초기 평가라는 점은 분리해서 봐야 한다.

기술적 함의

중요한 변화는 prompt → RTL이 아니라 spec → RTL → verification/PPA → feedback → RTL이다. 즉 생성 모델의 품질보다 synthesis·verification 같은 결정론적 EDA 도구를 평가 함수로 붙이는 orchestration이 실제 silicon 설계에서 더 중요해진다.

실무 연결

hand RTL과 HLS 결과를 비교하는 환경에서도 같은 구조를 만들 수 있다. golden C++ 비교, lint/sim, synthesis의 area/timing report를 자동 수집하고, AI는 실패 원인과 다음 수정 후보를 제안하도록 역할을 제한하면 훨씬 현실적이다. 특히 Stratus HLS를 붙일 때 ‘생성’보다 report-driven iteration 자동화가 먼저 효과를 낼 가능성이 높다.
